# write-app

これは、自分のアウトプットしたいことをより自由にラフに投稿できるアプリです。
また、コミュニティを作りより活発なアプリを目指す。

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features

- 個人メモ管理システム（フォルダー管理機能付き）
- Google認証ログイン
- レスポンシブデザイン
- Next.js 15.3.5 + TypeScript
- Tailwind CSS
- Next-Auth認証
