# 🚀 ランディングページ開発サーバー設定ガイド

## リモートアクセス対応済み設定

### 1. 迅速な起動方法

```bash
# スクリプトを使用して起動（推奨）
./start-dev.sh

# または手動で起動
npm run dev
```

### 2. アクセス方法

**ローカルアクセス:**
- http://localhost:3001

**リモートアクセス:**
- http://[あなたのIPアドレス]:3001
- 例: http://192.168.1.100:3001

### 3. IPアドレスの確認方法

**macOS/Linux:**
```bash
ifconfig | grep "inet " | grep -v 127.0.0.1
```

**Windows:**
```cmd
ipconfig
```

### 5. トラブルシューティング

**問題: サーバーが見えない**
```bash
# ポートが使用されていないか確認
lsof -i :3001

# ファイアウォール設定確認（必要に応じて）
```

**問題: スタイルが反映されない**
```bash
# Tailwind CSS のビルド確認
npm run build
```

**問題: ホットリロードが効かない**
- ブラウザのキャッシュをクリア
- 開発サーバーを再起動

### 8. 開発者向け情報

**主要ファイル構造:**
```
src/
├── app/(root)/page.tsx          # メインランディングページ
├── components/landing/
│   ├── Features.tsx            # 機能セクション
│   ├── Header/Navigation.tsx   # ナビゲーション
```

**機能ボタンの動作:**

4. 到達時にスポットライト効果
